# BETA-01.1 — Visual Polish / Responsive Refinement

Scope: presentation-only refinement for the closed beta. No calculation rules, datasets, or engine behavior were changed.

## Changes

- Unified responsive page gutters and maximum content widths.
- Removed horizontal overflow risk on narrow mobile screens.
- Improved hero typography and spacing.
- Improved card padding and vertical rhythm.
- Improved calculation-detail readability on mobile and desktop.
- Split the technical dataset trace into individual Table I / II / III entries instead of one long concatenated string.
- Improved wrapping of technical identifiers and version strings.
- Improved fixed bottom action bar sizing and safe-area handling.
- Added extra bottom content space so the fixed action bar cannot cover the last card.

## Out of scope

- AirDiveCalculator
- Table I / II / III values
- Rounding rules
- NDL logic
- Pressure groups
- Residual nitrogen
- Authentication / telemetry
